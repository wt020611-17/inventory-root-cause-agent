# 验收标准

## 1. 功能验收

### 风险识别

- 给定固定数据集、物料、仓库和分析日期，返回相同指标和风险等级。
- 支持正常、慢动、无动和数据质量阻断四类结果。
- 风险清单可按呆滞金额降序排列。
- 每个指标返回值、单位、观察窗口和计算日期。

### 根因分析

- 支持需求下降、超量采购、生产延期三类候选根因。
- 每个候选根因包含规则 ID、命中条件、得分、证据引用和建议动作。
- 多根因可共存并稳定排序；同分时按固定规则排序。
- 证据不足时明确返回，不将候选根因包装成已确认事实。

### Agent 与 API

- 自然语言问题能提取物料、仓库、分析日期和分析意图。
- 参数缺失时只询问必要信息，不猜测物料 ID。
- `/health`、结构化分析入口和自然语言入口契约稳定。
- LLM 不可用时自动降级为结构化结果或模板摘要。
- 所有响应包含 `trace_id`，并区分 `ok`、`empty`、`error`、`blocked`。

## 2. 数据验收

- 合成数据生成可通过固定 `seed` 复现。
- 必造场景全部存在并通过预期结果断言。
- 流水累计数量与结构化查询结果一致。
- 图关系不存在悬空节点。
- 每条记录明显标记为合成数据。
- 仓库中不存在真实凭据、客户信息、内部地址和公司专有表字段。

## 3. 测试验收

- 领域计算覆盖正常、临界值、零消耗、缺失和非法输入。
- 每条根因规则至少包含命中、不命中和证据不足用例。
- Repository 覆盖有数据、无数据和数据库异常。
- API 覆盖成功、参数错误、空结果、质量阻断和内部错误。
- 至少 12 条 Agent 评测样例，覆盖工具选择、参数抽取、两轮参数补全、任务完成、证据引用和安全降级。
- 新环境执行 `python -m pytest` 全部通过。

首版不虚构覆盖率指标。完成测试后再记录实际值，并把覆盖率门槛设为可复现的项目质量门。

## 4. 非功能验收

- Python 3.11+，公共函数有类型注解。
- Pydantic 输入模型拒绝未知字段。
- 业务层不直接依赖 FastAPI、具体数据库或具体图数据库。
- 阈值集中配置，分析函数显式接收 `as_of_date`。
- 日志不记录密钥和完整敏感输入。
- 图查询限制最大跳数、节点数和执行时间。
- 本地基线数据集的单次结构化分析目标为 2 秒内完成；实际结果以测量报告为准。
- Agent 设置最大执行步数；只有可重试依赖错误允许有限重试。

## 5. 演示验收

两分钟内完整展示：

1. 一个正常物料。
2. 一个多根因呆滞物料及证据链。
3. 一个无数据或 LLM 不可用的降级场景。
4. 测试与评测命令的可复现结果。
5. 生产延期证据能追溯到计划/实际开工日、状态和计划消耗数量。
